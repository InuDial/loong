# Release v0.1.2-alpha.1 Announcement

Loong v0.1.2-alpha.1 promotes the latest clean `dev` snapshot into the new `0.1.2` prerelease line.

## Highlights
- Strengthened the root `loong` operator path around `onboard`, `ask`, `chat`, and `doctor`.
- Expanded governed runtime seams across delegate delivery, session inspection, trajectory surfaces, and runtime capability flows.
- Hardened memory continuity with provenance-aware recall, staged hydration, pre-assembly systems, and compaction-related runtime truth.
- Broadened gateway-owned and runtime-backed delivery surfaces while keeping operator ownership explicit.
- Extended the shipped tool, provider, onboarding, and release-hardening baseline instead of widening into a second assistant runtime.

## Release Truth

This alpha is the governed local-assistant release line:

- one shipped `loong` product entry
- one shared governed runtime across CLI, gateway-owned delivery, and runtime-backed channels
- one explicit task-shaped delegated background-work surface

It should not be read as a full platform release for Web UI, plugin marketplace,
or richer browser-companion write automation yet.
